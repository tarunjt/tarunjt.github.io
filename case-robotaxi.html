AUTOMOTIVE / ENTERPRISE DASHBOARD

Robotaxi Test Suite

A command-center style dashboard for monitoring high-volume autonomous ride test runs, device status, scenario execution and operational deviations.

Role

Lead UX Designer

Duration

2026

Platform

Web dashboard · Mobile tester app

Methods

Wireframes · Dashboard UX · Scenario flows

Team / Context

Product, test operations and engineering

Overview

▥
100s Runs handled per day/hour
◷
Real-time Live device and scenario states
◎
Overview Designed for operational scanability

Problem / Challenge

When hundreds of runs are triggered, a simple list becomes unusable. The interface needed to show the operational picture first, then allow drill-down into scenarios, phones, nodes and deviations.

Constraints / Context

  • High-volume test execution without endless scrolling
  • Multiple devices and scenarios running simultaneously
  • Need to highlight deviations, ETA changes and run status
  • Outdoor/mobile-friendly tester workflows

Key Design Decisions

▥

Overview first

Aggregate status cards prevent the user from drowning in rows.

◎

Drill-down model

Users can inspect scenario detail only when needed.

◷

Live states

Running, queued, failed and complete states remain visible.

▣

Deviation focus

KPIs and exceptions receive priority over raw logs.

Outcome

  • Created a scalable dashboard approach for high-volume testing.
  • Separated executive overview from operational detail.
  • Established reusable cards for device, scenario and run-state monitoring.

Learnings

  • Complex UX needs clear states, constraints and prioritization.
  • Scannable structure matters as much as visual polish.
  • Reusable patterns improve handoff and future iteration.
