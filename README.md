# UX Portfolio Site

A lightweight static UX portfolio designed for GitHub Pages.

## Files
- `index.html` — homepage
- `case-cara.html` — CARA Voice Assistant case study
- `case-robotaxi.html` — Robotaxi Test Suite case study
- `case-d2c.html` — D2C WebView Redesign case study
- `case-museum.html` — Museum Website Redesign case study
- `case-ehr.html` — EHR Workflow Design case study
- `assets/styles.css` — visual styling
- `assets/script.js` — smooth scrolling helper

## Before publishing
1. Replace `your.email@example.com` with your email.
2. Replace placeholder LinkedIn/GitHub links in the footer.
3. Add `resume.pdf` or update the Resume button link.
4. Replace CSS-generated thumbnails with real screenshots when ready.
5. Review case-study copy for confidentiality before publishing.

## GitHub Pages
Upload the full folder contents to your repository. In GitHub, go to Settings → Pages and publish from the `main` branch root.
